# SBDC Marketing Studio: releases

Installers for **SBDC Marketing Studio**, the Windows desktop app for SBDC Maricopa marketing (the Marketing Calendar Kit, the Daybreak dashboard and Gemini drafts, with a person approving before anything is sent or published).

## Download

**[SBDC-Marketing-Studio-Setup.exe](https://github.com/poponline63/sbdc-marketing-desktop-releases/releases/latest/download/SBDC-Marketing-Studio-Setup.exe)** (always the newest version)

Run it once. No admin rights needed. If Windows says "Windows protected your PC", click **More info**, then **Run anyway** (the app is not code-signed yet). After that the app updates itself from this page.

This repository holds release files only. The source code is private.
